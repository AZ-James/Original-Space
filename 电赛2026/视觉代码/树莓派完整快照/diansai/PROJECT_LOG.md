# 电赛项目状态记录

更新时间：2026-08-01

## 1. 当前目标

摄像头检测管道内钢球位置，电机控制管道倾角，使钢球稳定到三个目标点之一。

当前工作分成三层：

1. 视觉层：稳定输出球的位置、速度、置信度和目标误差；
2. 电机层：快速发送使能、停止和小角度运动命令；
3. 控制层：视觉反馈 + 限幅PD控制（尚未接入，等待视觉实测）。

## 2. 已确认硬件

### 电机与RS485

- 电机：ZDT X42S；
- 地址：`0x01`；
- 波特率：115200，8N1；
- 固定校验字节：`0x6B`；
- 菜单串口功能：`UART_FUN`；
- 响应设置测试过 `Receive`、`Both`、`Other`；
- PL2303：树莓派 `/dev/ttyUSB0`，Windows `COM7`；
- FTDI模块：Windows `COM8`。

RS485接线：

```text
USB-RS485 A+  -> 电机 R/A/H（RS485板上为A）
USB-RS485 B-  -> 电机 T/B/L（RS485板上为B）
GND           -> 不连接（RS485隔离侧）
```

### 重要电气结论

`UART_FUN` 是串口命令功能，不会把RS485通信小板转换成TTL接口。
端子 `R/A/H`、`T/B/L` 的含义取决于电机安装的通信小板：TTL板为R/T，
RS485板为A/B，CAN板为H/L。树莓派GPIO不能直接连接当前RS485板的A/B。

## 3. 通信排查最终结果

已在Windows进行PL2303与FTDI模块交叉测试：

- PL2303 -> FTDI：三种RTS模式均完整收到测试字节；
- FTDI -> PL2303：三种RTS模式均完整收到测试字节；
- 两个模块在115200下均可双向通信；
- RTS高、低和发送后切换均不影响结果，模块具有自动方向控制。

两个模块分别连接电机后：

- `01 1F 6B` 读取版本：无返回；
- `01 3A 6B` 读取状态：无返回；
- `01 31 6B` 读取编码器：无返回。

因此已排除树莓派、Windows、PL2303、FTDI、RTS时序和Python权限问题。
当前结论是电机侧RS485通信小板的发送路径或固件响应异常。

直接GPIO测试收到连续`00`，原因是把TTL UART接到了RS485差分接口，该结果无效，
并且这种接法不应再次使用。

## 6. 电机程序原则

因为当前电机不返回数据，控制命令不能等待ACK，否则每条命令会阻塞视觉循环。
`zdt_motor.py`默认：

- 不操作RTS；
- 控制命令写入并flush后立即返回；
- 查询超时为80ms；
- 查询严格检查长度、地址和末尾`0x6B`；
- 直接运行脚本不会移动电机。

`motor_init.py`继续提供已经验证的手动锁定和解锁。编码器轮询由
`READ_ENCODER = False`关闭；更换正常通信板后才可设为`True`。

# 2026-08-01 鲁棒控制更新

## 核心结论

钢球系统不能使用“某角度持续某时间必然移动固定像素”的精确模型。轻微弧度、动静摩擦差异、每次装配/锁定偏移和钢球反射都会改变结果。一次实验得到的角度、速度和位移只能用于确定保守范围，不能当作固定标定常数。

当前 `pulse_controller.py` 已改成反馈驱动的自适应控制：

1. 每次动作前重新测量钢球位置和当前画面噪声；
2. 从 5.5°开始，未克服静摩擦才以 0.5°逐级增加，最高只到 7°；
3. 运动触发阈值由当前位置噪声的中位数绝对偏差（MAD）计算，并设宽松上下界；
4. 检测到真实位移或同方向速度后立即快速回到 0°；
5. 不预测滑行距离，等待真正稳定后重新测量落点，再决定下一步；
6. 换向后重新从小倾角搜索，不假设左右摩擦相同；
7. 视觉丢失、速度过高、进入边缘保护区或长期不稳定时均回零并中止；
8. ±30°机械硬限位仍独立存在（266 脉冲 = 29.925°），任何控制参数都不能越过；日常自适应动作另设 7°保守上限。

环境目前较稳定，因此只保留小范围角度自适应和简单噪声统计，不做复杂在线模型辨识。稳定判定窗口为 3 秒，兼顾可靠性和控制速度。

三个目标点和轨道四点继续从 `vision_calibration.json` 读取，装配小幅位移时只需修改该文件，不应修改控制算法。

## 本轮有效实验

- 当前锁定零位下，钢球曾在约 x=403 静止；这只是静摩擦造成的一个静止位置，不是唯一固定“最低点”。
- 在 x≈403 时，-1° 至 -5°未产生可信的永久运动；-6°能克服静摩擦。
- 快速 6°阶跃即使很短也会产生过大速度：一次 +6°约 0.124 秒后回零，钢球最大观测速度约 358 px/s，并接近右边缘。此方式已判定不适合继续使用。
- 将倾斜过程降到 5 RPM，并在检测到运动后回零，从 x≈413.6 到 x≈376.6，最大速度约 85.9 px/s。
- 再改为 3 RPM 慢速接近、直接使用原始视觉位置提前触发、80 RPM快速回零后，从 x≈376.7 到 x≈363～364，最大速度约 51.3 px/s。
- 中间目标 x=355，当前钢球距目标约 9 px，已进入 ±15 px 容差；测试结束时已发送绝对 0°。

上述数值只记录实验事实。程序不会依赖“每次移动约 13 px”之类的假设。

