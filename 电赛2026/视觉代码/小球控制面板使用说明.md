# 电赛小球控制面板使用说明

## 文件位置

- 控制面板程序：`/home/bg/Desktop/control_panel.py`
- 桌面快捷方式：`/home/bg/Desktop/小球控制面板.desktop`
- 项目代码目录：`/home/bg/diansai`
- 本说明文档：`/home/bg/Desktop/小球控制面板使用说明.md`

控制面板正常运行时不直接占用摄像头或电机串口，而是按按钮启动项目目录中的相应程序。任意时刻只允许一个摄像头/电机子程序运行，重复双击桌面图标也不会打开第二个面板。

运行按钮1、2或3时，摄像头画面会直接显示在总面板右侧。画面由实际控制进程低频发布，总面板不会再次打开物理摄像头，因此不会与闭环控制争用`/dev/video0`。主窗口已按树莓派实测的`1024×768`屏幕布局，画面不会跑到屏幕外。

## 启动方法

### 方法一：桌面快捷方式

双击桌面上的 **小球控制面板**。如果系统询问如何处理启动器，请选择“执行”或“信任并启动”。

### 方法二：终端

```bash
DISPLAY=:0 python3 /home/bg/Desktop/control_panel.py
```

## 按钮功能

### 1 — SEQUENCE

执行目标顺序：

```text
中目标点 → 左目标点 → 右目标点
```

控制面板依次运行：

```bash
python3 pulse_controller.py --target centre --max-pulses 12
python3 pulse_controller.py --target left   --max-pulses 12
python3 pulse_controller.py --target right  --max-pulses 12
```

只有前一步正常结束后才会执行下一步。若视觉丢失、速度过高、接近边缘或某一步失败，序列会停止，不会盲目继续。

### 2 — HOLD CENTRE

启动持续中点稳定：

```bash
python3 /home/bg/diansai/disturbance_stabilizer.py
```

程序持续运行，不设置自动结束时间。需要结束时必须点击红色 **STOP**，或者按键盘 `X`。

### 3 — INITIAL LOCK

执行初始位置锁零：

1. 摄像头检测钢球；
2. 确认钢球连续稳定约3秒；
3. 将当前机械位置设为电机相对零位；
4. 锁定电机；
5. 关闭串口，但电机继续保持锁定。

对应程序：

```bash
python3 /home/bg/diansai/lock_current_origin.py
```

该按钮不是“自动回到历史初始点”，而是把**当前人工调整好的机械位置**定义为本次运行的初始零位。

### 4 — COORD CONFIG

打开轨道及目标坐标配置窗口。

- 拖动 `Q1～Q4`修改轨道四角；
- 拖动`C/L/R`彩色竖线修改三个目标横坐标；
- 点击`SAVE CONFIG`保存；
- 目标纵坐标自动放在轨道中心线上。

保存文件：

```text
/home/bg/diansai/vision_calibration.json
/home/bg/diansai/vision_calibration.last_good.json
```

坐标配置窗口关闭后，总面板会重新读取并显示最新目标坐标。已经运行的控制程序不会热更新坐标，必须先停止再重新启动。

### STOP

向当前子程序发送`SIGINT`，让控制程序进入`finally`安全收尾并回到电机零位。即使恰好在“一键顺序”的两个步骤之间点击停止，后续步骤也不会继续启动。

如果子程序5秒内仍没有结束，面板才会强制终止；对于电机功能，强制终止后还会补发一次绝对零位命令。

## 键盘操作

| 按键 | 功能 |
|---|---|
| `1` | 中→左→右 |
| `2` | 持续保持中点 |
| `3` | 当前机械位置稳定3秒后锁零 |
| `4` | 打开坐标配置 |
| `X` | 停止当前子程序 |
| `Q` / `Esc` | 关闭控制面板；若子程序正在运行，会先请求停止 |

## 坐标参数传递

坐标关系如下：

```text
vision_calibration_gui.py
          │ 保存
          ▼
vision_calibration.json
vision_calibration.last_good.json
          │ 加载
          ▼
vision_calibration.py
          │
          ├─ pulse_controller.py
          ├─ disturbance_stabilizer.py
          ├─ lock_current_origin.py
          ├─ ball_controller.py
          ├─ relative_left_controller.py
          └─ vision_observe.py
```

主配置不存在或损坏时，程序自动使用`vision_calibration.last_good.json`。若两者都不可用，才使用代码内置初始坐标。

## 安全规则

1. 电机锁零之前，确认轨道实际角度接近机械水平零位。
2. 所有控制代码的绝对机械限制仍为`±30°`。
3. 不要在总面板以外手动同时运行第二个摄像头或电机程序。
4. 发现共振、钢球冲向边缘或视觉识别错误时，立即点击`STOP`。
5. 坐标配置窗口不控制电机，但会占用摄像头。
6. `INITIAL LOCK`会改变本次电机相对零位，只有人工调整完成后才使用。
7. 每次点击功能前，面板会检查摄像头、串口及程序文件；缺失时会显示中文原因并禁止启动。

## 状态说明

| 状态 | 含义 |
|---|---|
| `IDLE` | 没有子程序运行 |
| `STARTING` | 正在启动 |
| `RUNNING` | 当前功能运行中 |
| `COMPLETE` | 功能正常完成 |
| `STOPPING` | 正在安全停止 |
| `STOPPED` | 已停止 |
| `CONFLICT` | 检测到其他摄像头/电机程序 |
| `FAILED` / `ERROR` | 子程序失败或发生异常 |

窗口下方会显示子程序最近输出，例如钢球位置、目标误差、视觉丢失和安全停止原因。

## 常见问题

### 点击按钮后显示 CONFLICT

说明已有其他控制或视觉程序运行。先关闭对应程序，再点击按钮。

### 提示 ball not detected

检查：

- 摄像头是否被其他程序占用；
- 钢球是否在四边形检测范围内；
- 四角配置是否正确；
- 反光和阴影是否导致识别失败。

可以先通过按钮4重新配置坐标，或者运行：

```bash
DISPLAY=:0 python3 /home/bg/diansai/vision_observe.py
```

### 点击2后电机没有动作

程序只有连续获得可靠钢球位置后才会打开电机串口。视觉检测失败时安全联锁会禁止电机动作。
